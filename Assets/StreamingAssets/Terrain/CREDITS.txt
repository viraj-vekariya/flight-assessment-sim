These are loaded at runtime by TerrainTextures.cs from this StreamingAssets folder.
If a file is missing, the code falls back to a procedurally-generated texture, so
the project still runs with no texture files present. To swap in your own, replace
the .jpg here with the same file name (grass/dirt/rock/sand/snow.jpg).
