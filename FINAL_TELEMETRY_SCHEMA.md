## events.csv

| column | notes |
|--------|-------|
| `seq` | 1-based marker sequence within the trial |

| `t_host` | monotonic host clock, seconds since trial start — **the master clock** |
| `t_unix` | UTC unix seconds, ms resolution — for cross-machine alignment |
| `t_lsl` | liblsl `local_clock()`, or `-1` when LSL is not installed |

| `detail` | free text, commas replaced by `;` |
| `mission_phase` | CICTT-style phase of the mission |
| `altitude_m`, `airspeed_kmh`, `heading_deg` | aircraft state at the marker |
